# FlexFit

A sports subscription platform — one flexible membership to discover and
access gyms and fitness studios, with built-in community features.

## Demo

### Install the APK
1. Open the APK link on your Android phone.
2. Allow installation from unknown sources if prompted.
3. Install and launch the app.

## Tech stack
React Native (Expo) · ASP.NET Core 8 · MongoDB · SignalR
